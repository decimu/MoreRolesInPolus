# エスケーピスト（Escapist）仕様書

人狼ジャッジメントの「逃亡者」を移植する。役職の内部名は `escapist`、色は桜色（240, 150, 180）。
状態: 実装済み、ゲームでの確認はまだ（`MoreRolesInPolus/Scripts/Roles/Crewmate/Escapist.cs`）

## 原作の仕様（人狼ジャッジメント）

- 市民陣営。占いと霊能では「人狼でない」と出る
- 初日の夜を除いて、毎晩1人を選び、その人のところへ逃げ込む
- 逃げ込んだ先が人狼なら、逃亡者が死ぬ
- 逃げ込んだ先が襲撃されたら、逃亡者も死ぬ（逃げ込んだ先が狩人に守られていれば死なない）
- 自分の家が襲撃されても、逃げていれば死なない。逃げなければ死ぬ

## NoS での仕様

原作の「夜に逃げ込み先を選ぶ → 夜が明けて結果が出る」を、アモアスの「会議 → 追放 → タスク」に当てはめる。

| 項目 | 内容 |
|---|---|
| 陣営 | クルーメイト |
| 逃げ込み先を選ぶ | 会議中、投票画面のボタン（独裁者と同じ形）で1人選ぶ。最初の会議から使える |
| 選ばなかったとき | ふつうのクルーとして過ごす |
| 逃げ込み先がインポスターのとき | 追放のときに逃亡者が死ぬ |
| 逃げ込んでいるあいだ（次のタスク中） | 逃亡者はキルされない。ただし、タスクの画面を開いているあいだは守られない |
| 逃げ込み先が追放されたとき | 逃亡者も一緒に追放される |
| 逃げ込み先がキルされたとき | 逃亡者もその場で死ぬ |
| 視界 | 逃げ込んでいるあいだは狭くなる |
| アドミンとバイタル | 逃げ込んでいるあいだ、逃亡者は映らない（家にいないので見つからない） |
| 逃げ込みが切れるとき | 次の会議 |
| 護衛系の役職 | つなげない |

### タスクの画面を開いているあいだの判定

- 対象はタスクのミニゲームだけ。アドミン、カメラ、バイタルなどの画面は数えない
- 開いているかどうかは逃亡者本人の画面でしか分からないので、開いたときと閉じたときに逃亡者からホストへ知らせる。ホストは `PlayerCheckKilledEvent` で判定する
- 通信のずれで逃亡者が理不尽に殺されないよう、逃亡者に有利な側へ寄せる
  - 閉じたときは、閉じる操作の時点で先に知らせる
  - 開いた直後のキルは失敗することがあるが、NoS の盾の演出が出るのでインポスターにも分かる

### 追放画面の文

独自の文は出さない。NoS の「誰かが船を去ったようだ。」（設定 `options.meeting.noticeExtraVictims`）に任せる。

## 設定項目

| 設定 | 初期値（案） | 選べる値（案） |
|---|---|---|
| 逃げ込める回数 | 2回 | 1〜10回、無制限 |
| 続けて同じ人物に逃げ込める | オフ | オン、オフ |
| 逃げ込み中の視界 | 0.75倍 | 0.25〜1倍（0.125刻み） |
| アドミンとバイタルに映らない | オン | オン、オフ |

初期値は、実際に遊んでみてから詰める。

## 強さの見立て

- 強いところ: タスク中はほぼキルされない。追放のときに生きていれば逃げ込み先が白と分かるので、会議のたびに1人ずつ白が分かる
- 弱いところ: 逃げ込み先がキルされると逃亡者も死ぬ（インポスターは1回のキルで2人倒せることがある）。逃げ込み先がインポスターなら死ぬ。タスクの画面を開いているあいだは守られない。視界が狭くなる
- タスク中に死なない強さは、逃げ込める回数で調整する

## 実装で決めたこと（仕様書で未決定だった点）

- 同じ人に続けて逃げ込めるかは設定で選ぶ（初期値は「逃げ込めない」）
- 逃げ込み先に自分は選べない
- 逃げ込み先が追放されたときは、逃亡者も一緒に追放される
- 逃亡者自身が追放されたときは、逃げ込みはなかったことになる
- 一度選んだ逃げ込み先は、その会議の中では変えられない
- 死因は専用のものを使う。インポスターに逃げ込んで死んだときが「逃亡失敗」、逃げ込み先と一緒に追放されたときが「道連れ」、逃げ込み先と一緒にキルされたときが「連座」（ドクターのバイタルなどに出る）

翻訳キーは `achievement.moreRolesInPolus.escapist.<ID>.title` と `.goal`。

| ID | ランク | 称号 | 達成条件 |
|---|---|---|---|

| another2 | 銀・シークレット | 死なばもろとも | 逃げ込み先が追放され、道連れになる |
| challenge | 虹 | 逃げるは恥だが役に立つ | 1試合で2回以上キルを防ぎ、最後まで生き残ってクルーメイトとして勝利する |

## 実装のメモ

- 追放と一緒に死なせる: `MeetingHudExtension.ExileExtraVictims` まわり
- 会議のボタン: 独裁者の `CreateDiscussionButtons` と同じ作り
- キルを防ぐ: `PlayerCheckKilledEvent`（ホストでだけ発火する。判定に使う値は先に共有しておく）
- ミニゲームを開いているか: `Minigame.Instance`
- アドミンとバイタルに映さない: `PlayerAttributes.Isolation`（NoS のエイリアンが使っている）を次の会議まで付ける
- 視界: `LightRangeUpdateEvent`
