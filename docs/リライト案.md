# 役職の説明文のリライト案

NoS 本家の書き方に寄せた案です。本家は次のような書き方をしています。

- ひとこと（blurb）: 場面が浮かぶ短い言葉（「審判の時間」「斯くして奴は死んだ」）
- 説明（doc）: 「〜できるクルーメイトです。」の1文だけ。細かい決まりは能力の説明に任せる
- 能力の説明: 短く、大事な語を `<b>` で太字にする
- 設定画面の説明: 1〜3行

称号の達成条件は、遊びより正確さが大事な文なので対象外です。仕組み（何が起きるか）は変えていません。
`<br>` は改行です。1行は40字未満にしています。
