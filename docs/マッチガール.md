# マッチガール（Match Girl）仕様書

人狼ジャッジメントの「マッチ売り」を移植する。役職の表示名は「マッチガール」、内部名は `matchGirl`（英題 The Little Match Girl から）。色は夜明けの薄紫（200, 170, 230）。
状態: 仕様の確認中（未実装）

## 原作の仕様（人狼ジャッジメント）

- 市民陣営。占いと霊能では「人狼でない」と出る
- 毎晩、生きている人にマッチを使える。一度に何人にでも使える
- マッチを使った相手が人狼なら、幻を見せて、その夜の襲撃を失敗させる
- マッチを使い切ると、マッチ売り自身が死ぬ
- マッチの本数は設定で決める

## NoS での仕様

原作の「夜」を、アモアスの「会議 → 追放 → タスク」に当てはめる（エスケーピストと同じ考え方）。

| 項目 | 内容 |
|---|---|
| 陣営 | クルーメイト |
| 会議中に使う | 投票欄のマッチのボタンで相手を選ぶ。1回の会議で何人にでも使える |
| タスク中に使う | 能力ボタンで、近くにいる人にマッチを使う。クールダウンあり（設定で変える） |
| 相手がインポスターのとき | 幻を見せ、キルを封じる。会議中に使ったなら次のタスク中ずっと、タスク中に使ったならその場から次の会議まで、そのインポスターのキルはすべて失敗する |
| キルが失敗したとき | NoS の盾の演出を出す。インポスターの画面には幻（下記）を見せる |
| マッチ売りに分かること | 何も分からない（使った相手がインポスターだったかは知らされない） |
| 使い切ったとき | 会議中に最後の1本を使ったら、その会議の追放のときに死ぬ。タスク中に使い切ったら、その場で死ぬ。死因は「凍死」 |
| マッチの本数 | 設定で決める |

### アモアスならではの要素

- **停電の中で光る**: マッチを灯された人は、そのターンの停電中、周りが明るくなり、ほかの人からも見える
- **タスクでマッチを補充する**: タスクを決まった数だけ終えるごとに、マッチが1本増える
- **凍えた死体が手がかりになる**: マッチ売りがキルされ、その死体が通報されたときだけ、会議の初めに「最後にマッチを灯した相手」を全員に知らせる。追放や、使い切って死んだときは何も知らせない
- **幻を見せる**: マッチを灯されたインポスターがキルしようとすると、キルは失敗し、そのインポスターの画面にだけ、狙った相手の周りに生きているクルーの姿を借りた幻が3人ほど現れる（名前も出る）。幻は3秒ほどで薄れて消え、画面のふちがオレンジに一瞬光る。ほかの人の画面には何も映らない。NoS の幽霊役職ハルシネーションの作り（`VanillaAsset.GetPlayerDisplay`）をまねる

## 設定項目（案）

| 設定 | 初期値（案） |
|---|---|
| マッチの本数 | 3本 |
| タスク中に使うときのクールダウン | 20秒 |
| 補充に必要なタスクの数 | 3個 |
| 補充で持てるマッチの上限 | 5本 |
| 停電中に光る範囲 | 未定（作ってから見て決める） |

## 実装のメモ

- 会議のボタン: 独裁者・エスケーピストの CancelButton を複製する作り
- キルを防ぐ: `PlayerCheckKilledEvent`（ホスト）で `KillResult.ObviousGuard`
- 停電中の光: `LightRangeUpdateEvent` は自分の視界なので、ほかの人から見える光は別の作りが要る（要調査）
- 通報時の知らせ: `ReportDeadBodyEvent` と会議開始時の表示
- 死因: `NebulaAPI.Preprocessor.RegisterCommunicableText`（凍死）
- 幻: `Hallucination.HallucinationPlayer` の作り（`VanillaAsset.GetPlayerDisplay` で姿を作り、透明度を上げ下げする）
